# Словарь

Короткие определения для возвращения к знакомым понятиям.
Ссылки ведут к главам с примерами и объяснениями.

## Программа и инструменты

| Термин | Значение | Подробнее |
| --- | --- | --- |
| Исходный код | Текст программы на языке C | [Первая программа](guide/first-program.md) |
| Компилятор | Инструмент, который переводит исходный код и сообщает об обнаруженных ошибках | [Первая программа](guide/first-program.md) |
| Исполняемый файл | Результат сборки, который запускается как программа | [Первая программа](guide/first-program.md) |
| Терминал | Окно для работы с командной оболочкой: ввода команд и чтения их вывода | [Первая программа](guide/first-program.md) |
| Текущая папка | Папка, относительно которой программа ищет относительные пути | [Первая программа](guide/first-program.md) |
| Компоновщик | Инструмент, который соединяет объектные файлы и разрешает ссылки на функции и данные | [Несколько файлов](guide/modules.md) |
| Единица трансляции | Один исходный файл после обработки включений и других директив препроцессора | [Несколько файлов](guide/modules.md) |
| Заголовок | Обычно файл `.h` с объявлениями общего интерфейса | [Несколько файлов](guide/modules.md) |
| Препроцессор | Этап предварительной обработки директив и макросов | [Препроцессор](guide/preprocessor.md) |
| Макрос | Правило подстановки элементов исходного кода | [Препроцессор](guide/preprocessor.md) |

| Буфер | Область памяти для временного хранения или передачи данных | [Строки](guide/strings.md) |
| Объект | Область хранения данных в модели языка C | [Указатели](guide/pointers.md) |
| Адрес | Значение, позволяющее обратиться к объекту | [Указатели](guide/pointers.md) |
| Указатель | Значение указательного типа; может указывать на объект, функцию или быть нулевым | [Указатели](guide/pointers.md) |
| Разыменование | Обращение через указатель к тому, на что он указывает | [Указатели](guide/pointers.md) |

| `int**` | Указатель на объект, который сам хранит указатель на int | [Указатели](guide/pointers.md) |
| `NULL` | Макрос для обозначения нулевого указателя, который не указывает на объект | [Указатели](guide/pointers.md) |
| Область видимости | Часть текста, где имя обозначает данную сущность | [Время жизни](guide/lifetime.md) |
| Время жизни | Период выполнения, когда объект существует | [Время жизни](guide/lifetime.md) |
| Стек вызовов | Распространённая модель организации данных активных вызовов функций | [Время жизни](guide/lifetime.md) |
| Структура | Тип, объединяющий именованные поля, в том числе разных типов | [Структуры](guide/records.md) |
| Перечисление | Тип с набором именованных целочисленных констант | [Структуры](guide/records.md) |
| Связывание | Правило, определяющее, обозначают ли объявления имени одну сущность | [Несколько файлов](guide/modules.md) |
| Выравнивание | Требование к допустимому размещению объекта по адресам | [Структуры](guide/records.md) |
| Заполнение (padding) | Байты между полями или после них, не представляющие отдельное поле | [Структуры](guide/records.md) |
| VLA | Массив, размер которого задан неконстантным выражением и определяется при прохождении объявления | [Память](guide/memory.md) |
| Владелец памяти | Часть программы, отвечающая по договорённости за освобождение области | [Динамическая память](guide/memory.md) |
| Утечка памяти | Ситуация, когда выделенная память больше не нужна, но не освобождена | [Динамическая память](guide/memory.md) |
