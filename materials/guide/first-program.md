# Первая программа

{% include course-context.html %}

Программа — записанная последовательность действий для компьютера.
В этой главе появится программа, которая выводит одну строку. На её примере
разберём весь путь от текста до результата.

## Файл с текстом и готовая программа

**Исходный код** — текст на языке программирования. Его можно прочитать
и изменить в редакторе. Для C мы сохраняем его в файле с расширением `.c`,
например `hello.c`. Расширение — часть имени после последней точки.

Процессор не исполняет этот текст непосредственно. **Компилятор** переводит
код в машинные инструкции и сообщает об обнаруженных ошибках.
После сборки получается исполняемый файл: его уже можно запустить.

```text
hello.c → сборка → hello или hello.exe → запуск → строка на экране
```

Редактор нужен для изменения текста, компилятор — для сборки, терминал —
для ввода команд. Это разные инструменты; редактор может объединять их
в одном окне. Установка описана в [инструкции по настройке редактора](../../how_to_ide.md).

## Программа целиком

```c
{% include_relative examples/hello.c %}
```

Результат запуска:

```text
Hello, C!
```

Разберём каждую часть:

- `#include <stdio.h>` подключает объявления стандартных средств ввода и вывода.
  Здесь это позволяет компилятору узнать о `printf`.
- `int main(void)` начинает описание функции `main`. **Функция** — именованная
  часть программы. При обычном запуске выполнение нашего кода начинается с `main`.
  `void` в скобках означает отсутствие параметров, `int` перед именем —
  целочисленный результат. Свои функции появятся в шестой главе.
- `{` и `}` ограничивают тело функции — действия, которые она выполняет.
- `printf(...)` вызывает функцию вывода. Текст в двойных кавычках — строка.
  `\n` внутри неё обозначает перевод строки; эти два знака не печатаются буквально.
- `;` завершает инструкцию. После `printf` он обязателен.
- `return 0;` заканчивает `main` и сообщает системе об успешном завершении.
  Сам по себе `return` ничего не печатает.

C различает заглавные и строчные буквы: `main` и `Main` — разные имена.
Отступы помогают человеку видеть устройство программы.

## Как собрать и запустить

Можно просто читать пример и разбор. Для запуска сохраните код в `hello.c`
в отдельной папке, например `c-course`. При сохранении важно получить
`hello.c`, а не `hello.c.txt`.

**Текущая папка** — папка, относительно которой терминал ищет файлы.
Команда `cd` меняет её: `cd "путь к папке/c-course"`. Кавычки нужны,
если в пути есть пробелы. Посмотреть файлы можно командой `ls` на macOS/Linux
или `dir` в PowerShell.

macOS/Linux, из папки с `hello.c`:

```sh
cc -std=c17 -Wall -Wextra -Wpedantic hello.c -o hello && ./hello
```

Здесь `cc` — компилятор, `-std=c17` выбирает версию языка,
`-Wall -Wextra -Wpedantic` включают предупреждения, `-o hello` задаёт имя
готовой программы. `./hello` запускает файл из текущей папки.
`&&` разрешает запуск только после успешной сборки.

Windows, в **Developer PowerShell for VS**:

```powershell
cl /nologo /TC /std:c17 /W4 /utf-8 /D_CRT_SECURE_NO_WARNINGS hello.c /Fe:hello.exe
if ($LASTEXITCODE -eq 0) { .\hello.exe }
```

`cl` — компилятор MSVC, `/TC` выбирает C, `/std:c17` — версию языка,
`/W4` — предупреждения, `/utf-8` — кодировку исходного файла,
`/Fe:` — имя программы. `/D_CRT_SECURE_NO_WARNINGS` отключает предупреждения
MSVC, предлагающие заменить стандартные функции ввода-вывода его собственными
вариантами; мы используем стандартный C. Последняя строка запускает программу только при успешной
сборке. Это команды PowerShell, а не код C.

В следующих главах команды те же: достаточно заменить `hello.c` и имя
готовой программы. Для примера из нескольких файлов будут отдельные команды.
Готовые исходники и общие команды собраны в [каталоге примеров](../examples.md).

## Что происходит после изменения кода

Если заменить текст на `Good morning!`, сохранить файл и снова собрать его,
при следующем запуске появится новая строка. Если пропустить сборку,
запустится прежняя программа. Сохранение исходника само по себе не меняет
исполняемый файл.

**Ошибка компиляции** означает, что сборка не завершилась. Например, забытый
`;` может вызвать сообщение `expected ';'`. Начинайте с первой ошибки:
дальнейшие сообщения иногда оказываются её следствием. Номер строки указывает
место, где компилятор заметил проблему; причина может находиться строкой выше.

**Предупреждение** не всегда останавливает сборку, но указывает на подозрительное
место. **Ошибка в логике** может вообще не вызвать сообщения: программа соберётся,
но сделает не то, что мы задумали. В следующих главах будем разбирать такие случаи.

Итак, рабочий цикл состоит из четырёх действий: изменить текст, сохранить,
собрать, запустить. Следующая глава добавит в программу вычисления.
