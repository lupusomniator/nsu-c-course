# Условия и выбор

отрицательной температуре программа напечатает предупреждение о морозе.


Вывод — `Freezing`. В `if (temperature < 0)` выражение в скобках называется
**условием**. Если оно истинно, выполняется первый блок. Иначе выполняется
блок после `else`. За один проход выполняется ровно одна из двух ветвей.

`else` можно опустить: тогда при ложном условии программа просто продолжится
после блока `if`. Фигурные скобки объединяют инструкции в **блок**.

## Сравнения и логические операции

| Запись | Значение |
| --- | --- |
| `a < b`, `a > b` | Меньше, больше |
| `a <= b`, `a >= b` | Не больше, не меньше |
| `a == b`, `a != b` | Равно, не равно |
| `a && b` | Оба условия истинны |
| `a || b` | Хотя бы одно условие истинно |
| `!a` | Условие ложно |

Сравнение возвращает целое `1` при истине и `0` при лжи.
Сам `if` считает ноль ложью, а любое ненулевое значение — истиной.

`=` присваивает, `==` сравнивает. В `if (count = 0)` значение `count`
изменится на ноль, а условие окажется ложным. Это допустимая запись C,
но обычно ошибка замысла; предупреждения компилятора помогают её заметить.

Проверка диапазона записывается как `0 <= score && score <= 100`.
Математическую цепочку `0 <= score <= 100` использовать нельзя:
сначала получится `0` или `1`, а затем это число будет сравнено со `100`.

## Правая часть иногда не вычисляется

В `divisor != 0 && total / divisor > 2` деление выполняется только тогда,
когда первая часть истинна. Если делитель равен нулю, всё условие уже ложно.
Это **сокращённое вычисление** `&&`.

У `||` правая часть пропускается, если левая уже истинна. Поэтому порядок
проверок может обеспечивать безопасность следующей операции.

## Несколько случаев

Фрагмент внутри `main`:

```c
if (temperature < 0) {
    printf("Freezing\n");
} else if (temperature == 0) {
    printf("Zero\n");
} else {
    printf("Above zero\n");
}
```

Проверки идут сверху вниз. После выбора ветви остальные пропускаются.
Это отличается от нескольких независимых `if`, каждый из которых
проверяется отдельно.

Для выбора по конкретным целочисленным значениям есть `switch`:

```c
int command = 2;
switch (command) {
    case 1:
        printf("Start\n");
        break;
    case 2:
        printf("Stop\n");
        break;
    default:
        printf("Unknown\n");
        break;
}
```

`case` отмечает значение, с которого начнётся выполнение. `break` выходит
из `switch`; без него выполнение может продолжиться в следующем случае.
`default` используется, когда подходящей метки нет. Здесь выводится `Stop`.

## Выбрать значение выражением

Иногда ветви отличаются только значением, которое нужно получить:

```c
int larger;
if (left > right) {
    larger = left;
} else {
    larger = right;
}
```

Для уже объявленных `int left` и `int right` то же можно записать как
`int larger = left > right ? left : right;`.
Условный оператор `?:` сначала вычисляет условие перед `?`, затем ровно
одно из двух выражений: между `?` и `:` при истине или после `:` при лжи.
Если `left == 4`, `right == 9`, выбирается значение 9.
Это выражение с результатом, поэтому его можно использовать в присваивании
или `return`. Для длинных действий обычный `if` читается яснее.

## Как увидеть ошибку в условии

Для условия `temperature < 0` полезно рассмотреть три значения: `-1`, `0`, `1`.
Ноль — **граничный случай**: именно здесь различаются `<` и `<=`.
Проверка только значения `-10` не обнаружит случайно написанное `<=`.

В следующей главе значение перестанет быть записанным в исходнике:
программа получит его от пользователя.
