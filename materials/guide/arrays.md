# Массивы

{% include course-context.html %}

Пусть у нас есть четыре измерения температуры. Четыре отдельные переменные
неудобно обходить циклом.
**Массив** хранит несколько элементов одного типа,
а нужный элемент выбирается по номеру — **индексу**.

## Индексы начинаются с нуля

```c

```

Вывод — `sum=18, count=4`.

В `int values[4] = {3, 7, 2, 6};` создаётся массив из четырёх `int`.
Фигурные скобки справа перечисляют начальные значения.

```text
Индекс:       0   1   2   3
Значение:     3   7   2   6
```

`values[0]` обозначает первый элемент, `values[3]` — последний.
Элемент можно читать и изменять: `values[1] = 10;` заменит только второе число.

Для массива из `n` элементов допустимы индексы от `0` до `n - 1`.
Элемента `values[4]` в нашем массиве нет. C не проверяет границы автоматически:
выход за них имеет неопределённое поведение. Возможны падение, повреждение
соседних данных или внешне нормальный результат. Последний не доказывает корректность.

## Обход массива

Цикл начинает с `i == 0`, читает `values[i]`, затем увеличивает `i`.
Условие `i < count` прекращает обход **до** недопустимого индекса `4`.
После каждого шага `sum` хранит сумму уже обработанных элементов.

`sizeof` сообщает размер объекта или типа в байтах. В нашем случае
`sizeof(values)` — размер всего массива, `sizeof(values[0])` — размер элемента.
Их отношение равно числу элементов независимо от того, сколько байтов занимает `int`.

Результат `sizeof` имеет тип `size_t` — беззнаковый целочисленный тип для размеров.
Его определение доступно, в частности, через `<stdio.h>`. Для вывода `size_t`
нужен `%zu`. Беззнаковый означает, что отрицательных значений у типа нет.

Этот способ определения длины работает там, где `values` — настоящий массив.
В параметре функции запись массива имеет другое значение; к этому вернёмся
в главе об указателях.

## Вместимость и заполненная часть

У `int values[100]` есть место для ста чисел. Но программа могла прочитать
только семь. Тогда **вместимость** равна 100, а **число используемых элементов** — 7.
Эту длину хранят отдельно и обходят только заполненную часть.

Массив `int values[100] = {0};` полностью инициализируется нулями.
В `int values[4] = {3, 7};` оставшиеся два элемента тоже будут нулевыми.
Локальный массив `int values[4];` без инициализации таких гарантий не имеет.

## Копирование и обмен

Массивам нельзя присваивать друг друга целиком через `=` после объявления.
Для копирования элементов подходит цикл:

```c
int source[3] = {4, 8, 1};
int destination[3] = {0};
for (int i = 0; i < 3; ++i) {
    destination[i] = source[i];
}
```

Обмен двух элементов требует временного места. Если сначала написать
`values[0] = values[1]`, старое значение первого элемента потеряется.

```c
int temporary = values[0];
values[0] = values[1];
values[1] = temporary;
```

## Массив массивов

Таблица может быть массивом строк, каждая из которых сама массив:

```c
int table[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

Здесь две строки по три элемента. `table[1][2]` — число `6`: сначала
выбирается строка с индексом 1, затем её элемент с индексом 2.
Оба индекса должны находиться в своих границах.

Особенно важный случай массива — строка текста. У неё есть собственное
соглашение о том, где заканчиваются полезные данные.
