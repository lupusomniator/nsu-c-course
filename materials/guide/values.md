# Переменные и вычисления

{% include course-context.html %}

В первой программе текст был известен заранее. Теперь программа будет хранить
данные и вычислять результат: сколько стоит несколько одинаковых товаров.

## Переменная связывает имя со значением

```c

```

Вывод:

```text

60
2 90
```

В `int price = 30;` слово `int` задаёт тип: здесь хранятся целые числа.
`price` — имя переменной, `30` — начальное значение. Создание переменной
с начальным значением называется **инициализацией**.

**Тип** определяет допустимые значения и операции над ними. Для начала нам
нужны `int` для целых чисел и `double` для приближённых дробных чисел.
У обоих типов есть ограничения; бесконечно большое число в них не поместится.

`price * count` — **выражение**. Программа вычисляет его значение и сохраняет
в `total`. Знак `*` обозначает умножение.

## Присваивание не создаёт постоянную связь

`count = 2;` заменяет значение уже существующей переменной. Это **присваивание**,
а не математическое утверждение о равенстве. Сначала вычисляется правая часть,
затем результат записывается в левую.

| После строки | `price` | `count` | `total` |
| --- | ---: | ---: | ---: |
| `int total = price * count;` | 30 | 3 | 90 |
| `count = 2;` | 30 | 2 | 90 |
| `total = price * count;` | 30 | 2 | 60 |
| `total = total + price;` | 30 | 2 | 90 |

`total` хранит результат вычисления, а не формулу. Изменение `count`
не пересчитывает его автоматически. В последней строке используется старое
значение `total`, к нему прибавляется `price`, затем сохраняется сумма.

`total += price;` — сокращение такого прибавления. Для уменьшения есть `-=`,
для умножения — `*=`, для увеличения на единицу — `++total`.
Пока будем записывать изменение отдельной инструкцией.

## Вывод значений

В `printf("%d\n", total)` последовательность `%d` — место для значения типа
`int`. После строки формата перечисляются значения для подстановки.
`printf("%d %d\n", count, total)` выводит два числа через пробел.

Строка формата должна соответствовать типам: для `int` используем `%d`,
для вывода `double` — `%f`. В `%.2f` число `2` задаёт количество цифр после точки.

## Деление зависит от типов операндов

**Операнды** — значения, над которыми выполняется операция:
в `7 / 2` это `7` и `2`.

```c
int whole = 7 / 2;       // 3
int remainder = 7 % 2;   // 1
double half = 7.0 / 2.0; // 3.5
double surprise = 7 / 2; // 3.0
```

Это фрагмент для тела `main`, а не отдельная программа. `//` начинает
комментарий до конца строки; компилятор его не исполняет.

При делении целых дробная часть отбрасывается к нулю: `-7 / 2` даёт `-3`.
Оператор `%` вычисляет целочисленный остаток: `7 == (7 / 2) * 2 + 7 % 2`.
Делить на ноль и вычислять остаток от деления на ноль нельзя.

В `double surprise = 7 / 2;` сначала получается целое `3`, затем оно
преобразуется в `3.0`. Тип переменной слева не меняет уже выполненное деление.
Запись `7.0` задаёт дробный литерал типа `double`. **Литерал** — значение,
написанное непосредственно в коде.

## Порядок действий и ограничения

Умножение и деление выполняются раньше сложения и вычитания:
`2 + 3 * 4` даёт `14`, а `(2 + 3) * 4` — `20`.
Скобки позволяют явно задать группировку.

Локальная переменная `int value;` не получает надёжного начального значения.
Читать её до записи нельзя. Для счётчика удобно сразу писать `int value = 0;`.

Диапазон `int` ограничен. Если результат знакового целочисленного вычисления
не помещается, язык не обещает корректного результата. Это пример
**неопределённого поведения**: полагаться на наблюдаемый вывод нельзя.
Пока используем небольшие числа; диапазоны подробно разберём в главе о битах.

Дробные значения обычно приближённые: `double` не хранит любую десятичную
дробь точно. Для первых формул достаточно помнить об этом ограничении.

Теперь программа умеет вычислять значения. Следующий шаг — выбирать действие
в зависимости от этих значений.
