# Циклы и состояние программы

Если граница меняется, удобнее описать повторяемое действие: добавить
очередное число и перейти к следующему.

## Цикл while

```c
{% include_relative examples/loops.c %}
```

Вывод — `10`. **Цикл** повторяет блок, пока условие истинно.
Каждое выполнение этого блока называется **итерацией**.

В `while` сначала проверяется условие, затем выполняется тело.
После тела управление возвращается к проверке.

| Проверяем `next <= 4` | После `sum += next` | После `++next` |
| --- | ---: | ---: |
| `1 <= 4`, истина | 1 | 2 |
| `2 <= 4`, истина | 3 | 3 |
| `3 <= 4`, истина | 6 | 4 |
| `4 <= 4`, истина | 10 | 5 |
| `5 <= 4`, ложь | Тело не выполняется | — |

Перед каждой проверкой `sum` содержит сумму чисел **до** `next`.
Это постоянное свойство состояния называется **инвариантом цикла**.
Оно помогает объяснить, почему после выхода в `sum` находится нужная сумма.

Если убрать `++next`, условие останется истинным: цикл не продвинется к выходу.
В терминале такую программу обычно можно прервать сочетанием Ctrl+C.

## Та же идея с for

Фрагмент для тела `main`:

```c
int sum = 0;
for (int next = 1; next <= 4; ++next) {
    sum += next;
}
printf("%d\n", sum);
```

У `for` три части: начальное действие; условие продолжения; действие
после итерации. Начальное действие выполняется один раз. Затем чередуются
проверка, тело и шаг. Если условие ложно сразу, тело не выполняется ни разу.

Имя `next`, объявленное в заголовке `for`, доступно в самом цикле.
После цикла это имя уже недоступно. Подробнее о таких границах — в главе
об областях видимости.

`while` удобно читать как «пока не наступило событие», а `for` — как
«пройти последовательность значений». Во многих случаях возможны оба варианта.

## Счётчик и накопитель

Переменная может хранить число обработанных элементов, сумму, текущий минимум
или признак того, что уже встретилось нужное значение.

Для суммы начальное значение `0` подходит: добавление к нему первого числа
даёт это число. Для минимума ноль обычно не подходит. Например, минимум
из `5`, `8`, `6` равен `5`, но переменная, изначально равная нулю и только
уменьшающаяся, так и останется нулём. Начальный минимум можно взять из первого
элемента, отдельно учитывая случай, когда элементов нет.

## Выход и пропуск итерации

`break` выходит из ближайшего цикла. `continue` пропускает остаток тела
и переходит к следующему шагу: у `for` это действие после итерации,
у `while` — проверка условия.

Например, этот фрагмент печатает `1 2 4 5 `:

```c
for (int value = 1; value <= 5; ++value) {
    if (value == 3) {
        continue;
    }
    printf("%d ", value);
}
```

В `while` легко случайно пропустить изменение счётчика через `continue`
и получить бесконечный цикл. Для простого обхода предпочтительна простая
структура без лишних выходов.

Есть также `do { ... } while (условие);`: он проверяет условие после тела,
поэтому выполняет тело хотя бы один раз.

## Проверка границ

У суммы от 1 до `limit` полезно различать `limit == 0`, `limit == 1`
и обычное положительное значение. При нуле цикл не выполняется,
при единице выполняется ровно один раз. Так заметнее ошибки `<` вместо `<=`.

Если границу вводит пользователь, нужно учитывать и диапазон суммы:
даже если каждое слагаемое помещается в `int`, сумма может не поместиться.
В нашем полном примере числа фиксированы и малы.
