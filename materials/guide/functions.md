# Функции

{% include course-context.html %}

У повторяющегося вычисления может быть своё имя. Функция позволяет отделить
смысл действия от места, где оно понадобилось.

## Параметр и результат

```c

```

Вывод — `10 11`. Разберём определение:

```c
int AddOne(int value) {
    return value + 1;
}
```

Первый `int` — тип результата. `AddOne` — имя функции. `int value` —
**параметр**, локальная переменная, которая получает переданное значение.
`return` завершает вызов и возвращает результат вычисления вызывающему коду.

В `AddOne(original)` выражение `original` — **аргумент**.
Аргумент находится в месте вызова, параметр — в определении функции.

| Шаг | Что происходит |
| --- | --- |
| 1 | В `main` переменная `original` хранит `10` |
| 2 | Вызов создаёт параметр `value` со значением `10` |
| 3 | `value + 1` даёт `11`; функция возвращает его |
| 4 | Выполнение `main` продолжается; в `result` записывается `11` |

Сам вызов является выражением со значением `11`. Поэтому его можно
использовать при присваивании, в условии или как часть другого выражения.

## Передача по значению

В C аргументы передаются **по значению**: параметр получает копию.
Даже если внутри функции написать `value = 100;`, `original` от этого
не изменится. Имена в разных функциях могут совпадать, но это не делает
переменные общими.

Функция также не видит локальные переменные вызывающей функции по их именам.
Чтобы получить данные, ей нужны параметры. Возможность изменить исходный
объект через его адрес появится в главе об указателях.

## Несколько параметров и отсутствие результата

Параметры разделяются запятыми:

```c
int Max(int left, int right) {
    if (left > right) {
        return left;
    }
    return right;
}
```

`Max(3, 8)` возвращает `8`. После первого `return` выполнение функции
заканчивается, поэтому `else` здесь не обязателен.

Если функция выполняет действие и не возвращает значение, тип результата —
`void`:

```c
void PrintSeparator(void) {
    printf("---\n");
}
```

`void` в скобках означает отсутствие параметров. Вызов — `PrintSeparator();`.
В такой функции можно написать `return;` без значения для раннего выхода.
В приведённом примере выполнение просто доходит до закрывающей скобки.

## Объявление и определение

Компилятор читает исходник по порядку. До вызова ему нужна информация
об имени, типе результата и параметрах функции.

```c
int AddOne(int value); // Объявление: функция существует, вот её интерфейс.
```

Объявление с типами параметров называется **прототипом**.
Определение с телом одновременно является объявлением. Поэтому в полном
примере достаточно поместить определение `AddOne` перед `main`.
Прототип позволяет разместить тело позже; отдельные файлы разберём в главе о модулях.

## Что обещает функция

У `AddOne` есть ограничение: прибавление единицы должно помещаться в `int`.
У функции вычисления среднего может быть другое: элементов должно быть
хотя бы один. Такие условия стоит писать рядом с функцией.

Полезно отделять вычисление от вывода: `Max` возвращает число, а вызывающий
код решает, печатать его, сравнивать с другим или использовать дальше.
Это делает назначение функции понятнее и позволяет проверять вычисление отдельно.

Дальше понадобится хранить несколько однотипных значений под одним именем —
для этого в C есть массивы.
