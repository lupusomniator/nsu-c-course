### Идея

Считываем три значения типа `float`, вычисляем `x * k + b` и печатаем результат
с двумя знаками после точки. Умножение имеет больший приоритет, чем сложение,
поэтому формула непосредственно записывается на Си.

Для `23.5 1.2 -2.0` получаем `23.5 * 1.2 - 2.0 = 26.2`, то есть `26.20`
в требуемом формате. Для `12.12 1.10 0` результат до округления — `13.332`,
а в ответе нужно `13.33`.

### На что обратить внимание

- В `scanf` спецификатор `%f` нужен для переменной типа `float`;
  перед каждой переменной ставится `&`. `%lf` предназначен для `double`
  и при чтении в `float` использоваться не должен.
- `printf("%.2f", temperature)` выводит ровно два знака после точки,
  включая завершающие нули. При передаче в `printf` значение `float`
  автоматически преобразуется в `double`.
- Не нужно самостоятельно умножать на 100 и отбрасывать дробную часть:
  такое усечение не равно округлению, особенно для отрицательных чисел.
- Десятичные дроби не всегда представимы в `float` точно. В этой задаче
  тесты подобраны так, чтобы небольшая погрешность вычислений не меняла
  округление до двух знаков.
- Проверка допускает абсолютную погрешность `0.0001` относительно округлённого
  эталона. `-0.00` и `0.00` равнозначны. Требование использовать `float`
  и печатать два знака после точки нужно соблюдать по условию, даже если
  числовая проверка сама по себе не контролирует оформление и тип переменных.

Время и дополнительная память — `O(1)`.
