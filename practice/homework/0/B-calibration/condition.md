# B. Калибровка датчика

Датчик температуры на сервере нуждается в калибровке. Чтобы получить исправленную температуру, Маша умножает показание датчика `x` на коэффициент `k` и прибавляет поправку `b`.

Вычислите исправленную температуру по формуле `t = x * k + b`.

В этой задаче используйте тип `float` для показания датчика, коэффициента, поправки и результата.

## Формат ввода

В одной строке записаны три вещественных числа `x`, `k`, `b` в указанном порядке.

Ограничения: `−100 ≤ x ≤ 100`, `0 ≤ k ≤ 2`, `−100 ≤ b ≤ 100`. Каждое число содержит не более двух знаков после десятичной точки. Дробная часть отделяется точкой.

## Формат вывода

Выведите исправленную температуру, округлённую до двух знаков после десятичной точки. Выводите оба знака, даже если они равны нулю.

Ответ сравнивается с округлённым эталоном с абсолютной погрешностью не более `0.0001`. Значения `0.00` и `-0.00` считаются равными.

## Пример 1

Ввод:

```text
23.5 1.2 -2.0
```

Вывод:

```text
26.20
```

## Пример 2

Ввод:

```text
12.12 1.10 0
```

Вывод:

```text
13.33
```

## Пример 3

Ввод:

```text
-10 0.5 3
```

Вывод:

```text
-2.00
```

## Примечание

В первом примере `23.5 * 1.2 - 2.0 = 26.2`, поэтому ответ — `26.20`. Во втором примере результат до округления равен `13.332`.

Для чтения переменной типа `float` используйте спецификатор `%f`, а для вывода двух знаков после точки — `%.2f`.

Тесты подобраны так, чтобы небольшая погрешность вычислений типа `float` не влияла на округление до двух знаков.
