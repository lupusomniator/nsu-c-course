# A. Время до запуска

Маша готовит запуск нового сервера. Таймер показывает, сколько секунд осталось до запуска, но большое число секунд неудобно читать.

Представьте этот промежуток времени в годах, днях, часах, минутах и секундах. Сначала выделите максимально возможное количество полных лет, затем из оставшегося времени — полные дни, часы и минуты.

В этой задаче в году всегда 365 дней: високосных годов не существует. В сутках 24 часа, в часе 60 минут, в минуте 60 секунд.

## Формат ввода

Одно целое число `s` — количество секунд, `0 ≤ s ≤ 2000000000`.

## Формат вывода

Выведите пять целых чисел через пробел: количество лет, дней, часов, минут и секунд, именно в таком порядке.

Количество дней должно быть от 0 до 364, часов — от 0 до 23, минут и секунд — от 0 до 59. Нулевые компоненты тоже нужно вывести.

## Пример 1

Ввод:

```text
31539661
```

Вывод:

```text
1 0 1 1 1
```

## Пример 2

Ввод:

```text
0
```

Вывод:

```text
0 0 0 0 0
```

## Пример 3

Ввод:

```text
2000000000
```

Вывод:

```text
63 153 3 33 20
```

## Примечание

В первом примере 31539661 секунда — это 1 год, 0 дней, 1 час, 1 минута и 1 секунда.

Все вычисления в этой задаче помещаются в тип `int`. Используйте целочисленное деление и остаток от деления.
