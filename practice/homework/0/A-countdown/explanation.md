### Идея

Разбираем длительность от самых крупных единиц к самым мелким.
Целочисленное деление даёт число полных единиц, а остаток от деления — то,
что ещё предстоит распределить.

| Единица | Сколько в ней секунд |
| --- | ---: |
| Год | `365 * 24 * 60 * 60 = 31536000` |
| День | `24 * 60 * 60 = 86400` |
| Час | `60 * 60 = 3600` |
| Минута | `60` |

Сначала находим годы: `years = remaining / 31536000`.
Затем `remaining %= 31536000` оставляет только секунды, не вошедшие в полные годы.
Таким же способом выделяем дни, часы и минуты. Последний остаток — секунды.

Для `31539661` получаем `1` год и остаток `3661` секунд, затем `0` дней,
`1` час, `1` минуту и `1` секунду.

### Почему это работает

Для положительного делителя `d` и неотрицательного числа `n` выполняется
`n = (n / d) * d + n % d`, причём остаток меньше `d`.
На каждом шаге деление выделяет максимально возможное число полных единиц,
а остаток не теряет ни одной секунды. Поэтому итоговая запись сохраняет
исходную длительность и соблюдает границы каждой компоненты.

### На что обратить внимание

- После каждой крупной единицы обновляем остаток. Если делить исходное число
  на `86400`, получим общее количество дней, включая уже учтённые годы.
- Год в этой задаче всегда содержит 365 дней. Для длительности 366 дней
  результат начинается с `1 1`.
- Нулевые компоненты тоже выводятся. Для `0` ответ — пять нулей.
- Достаточно `int`: вход не превосходит двух миллиардов, а промежуточные
  значения не больше входного числа. Вещественное деление не требуется.

Число операций фиксировано: время и дополнительная память — `O(1)`.
