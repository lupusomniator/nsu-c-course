# Домашка #0

Три задачи на основы Си: типы `int`, `float`, `char`, арифметические операторы,
ввод-вывод, условия и циклы. У каждой задачи есть полный разбор и решение под катом,
заготовка `main.c` и 100 тестов для самостоятельной проверки.

[Как клонировать репозиторий и подготовить инструменты](../../../tasks.md).
Команды для Windows находятся внутри разбора каждой задачи;
вариант для macOS/Linux — под отдельным катом.

| Задача | Тема | Тестов |
| --- | --- | ---: |
| [A. Время до запуска](A-countdown/condition.md) | `int`, целочисленное деление и остаток | 100 |
| [B. Калибровка датчика](B-calibration/condition.md) | `float`, формула и форматированный вывод | 100 |
| [C. Таблица ASCII](C-ascii/condition.md) | `char`, коды символов, условия и цикл | 100 |

## Как сравниваются ответы

- В A пробелы и переводы строк между числами несущественны. Используйте обычную
  десятичную запись без ведущего плюса и лишних нулей.
- В B сравниваются числа с абсолютной погрешностью не более `0.0001` относительно
  округлённого эталона. `0.00` и `-0.00` равнозначны.
- В C сравнивается точный текст таблицы, включая пробелы и переводы строк.
  Окончания строк LF и CRLF считаются одинаковыми.

Все 300 тестов перенесены из исходного набора домашки; примеры входят в их число.
Требования использовать `float`, `char` и цикл проверяйте по коду — тесты
проверяют результат программы. Числовой проверяющий модуль для B собирается
автоматически вместе с задачей; устанавливать Python для запуска тестов не нужно.

## Проверить все готовые решения

В Developer PowerShell перейдите из корня репозитория в папку домашки:

```powershell
cd practice/homework/0
cmake -S . -B build-solution -G "NMake Makefiles" -DCOURSE_USE_SOLUTIONS=ON
if ($LASTEXITCODE -ne 0) { throw "Не удалось настроить сборку" }
cmake --build build-solution
if ($LASTEXITCODE -ne 0) { throw "Исправьте ошибки компиляции" }
ctest --test-dir build-solution --output-on-failure
```

Для проверки всех своих `main.c` используйте папку `build` вместо
`build-solution` и параметр `-DCOURSE_USE_SOLUTIONS=OFF`.
