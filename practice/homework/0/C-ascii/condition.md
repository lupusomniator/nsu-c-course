# C. Таблица ASCII

Маша составляет таблицу символов для программы. В кодировке ASCII каждому символу соответствует целое число от 0 до 127. Среди этих символов есть буквы, цифры, знаки препинания, пробел и управляющие символы.

Даны два кода `a` и `b`. Выведите таблицу для всех кодов от `a` до `b` включительно, в порядке возрастания.

Для кодов от 33 до 126 представлением является сам символ ASCII. Для кода 32 используйте слово `SPACE`. Для кодов от 0 до 31 и кода 127 используйте слово `CONTROL`. Служебные символы выводить непосредственно не нужно.

В решении используйте цикл. Для вывода символа с кодом от 33 до 126 сохраните его код в переменную типа `char` и выведите эту переменную как символ.

## Формат ввода

Два целых числа `a` и `b`, разделённые пробелом: `0 ≤ a ≤ b ≤ 127`.

## Формат вывода

Для каждого кода выведите отдельную строку: десятичный код без ведущих нулей, один пробел и представление символа.

Печатные символы выводите без кавычек. Слова `SPACE` и `CONTROL` выводите заглавными латинскими буквами. Всего должно получиться `b - a + 1` строк.

## Пример 1

Ввод:

```text
30 35
```

Вывод:

```text
30 CONTROL
31 CONTROL
32 SPACE
33 !
34 "
35 #
```

## Пример 2

Ввод:

```text
65 67
```

Вывод:

```text
65 A
66 B
67 C
```

## Пример 3

Ввод:

```text
126 127
```

Вывод:

```text
126 ~
127 CONTROL
```

## Примечание

Число, записанное в переменную типа `char`, можно вывести как символ с помощью `%c` или как десятичный код с помощью `%d`. Например, коду 65 соответствует символ `A`.

Для счётчика цикла используйте тип `int`: после обработки кода 127 счётчик должен увеличиться до 128. Для записи печатного кода в переменную `char` можно использовать обычное присваивание.

В тестирующей среде коды символов от 0 до 127 соответствуют ASCII.
