# Домашка #1 — Массивы и матрицы

Шесть задач про хранение показаний, индексы и преобразование массивов.
У каждой есть условие с тремя примерами, пошаговый разбор и полное решение
в раскрываемом блоке «Разбор и решение». Разборы можно читать сразу.

Для запуска доступны заготовка `main.c`, готовое решение `solution.c`
и 50 тестов на задачу. [Инструкция по инструментам и сборке](../../../tasks.md)
объясняет, как подготовить среду. Команды Windows и macOS/Linux приведены
также внутри каждого разбора.

| Задача | Что разбираем | Тестов |
| --- | --- | ---: |
| [A. Лента из будущего](A-reverse/condition.md) | Разворот участка, встречное движение индексов, обмен через временную переменную | 50 |
| [B. Карусель с характером](B-rotate/condition.md) | Циклический сдвиг вправо, остаток от деления и отдельный массив результата | 50 |
| [C. Архив привидений](C-archive/condition.md) | Различие индекса и значения, повторные запросы к сохранённым данным | 50 |

## Как устроены решения и тесты

Индексы во всех задачах начинаются с нуля. Достаточно массивов фиксированного
размера: до 1000 элементов или до 100 строк и столбцов. В коде используются
обычные циклы и `int`; условия гарантируют размеры и значения в указанных
диапазонах. Каждое чтение проверяется: если вместо нужных чисел вход закончится,
программа завершится с кодом 1.

Все 300 пар тестов перенесены из исходного набора домашки без изменения
содержимого. Первые три теста каждой задачи — примеры из условия.
Проверяется последовательность целых чисел: пробелы и переводы строк между
ними равнозначны. Решения при этом соблюдают показанное в условиях разбиение
на строки. Использование массива проверяется по исходному коду; совпадение
вывода само по себе не доказывает способ решения.

## Проверить все готовые решения

В Developer PowerShell перейдите из корня репозитория в папку домашки:

```powershell
cd practice/homework/1
cmake -S . -B build-solution -G "NMake Makefiles" -DCOURSE_USE_SOLUTIONS=ON
if ($LASTEXITCODE -ne 0) { throw "Не удалось настроить сборку" }
cmake --build build-solution
if ($LASTEXITCODE -ne 0) { throw "Исправьте ошибки компиляции" }
ctest --test-dir build-solution --output-on-failure
```

Для проверки всех своих `main.c` используйте папку `build` вместо
`build-solution` и параметр `-DCOURSE_USE_SOLUTIONS=OFF`.
