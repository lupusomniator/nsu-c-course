# B. Карусель с характером

На фестивале Маше достался стенд с числовой каруселью: в ряд стоят `n` окошек, в каждом видно целое число. Рядом большая кнопка с надписью «НЕ НАЖИМАТЬ». Разумеется, к открытию фестиваля её уже успели нажать.

Каждое нажатие передвигает числа на одно окошко вправо. Число из крайнего правого окошка при этом появляется в крайнем левом — с карусели никто не сходит. На самой кнопке работает только счётчик: он показывает `k` нажатий. Окошки временно погасли, а ведущий уже просит назвать результат.

У Маши есть фотография чисел до первого нажатия. Восстановите, что должно появиться в окошках после всех `k` нажатий. Если кнопку всё-таки никто не трогал, на счётчике будет ноль.

## Формат ввода

В первой строке записаны количество окошек `n` и число нажатий `k`, `1 ≤ n ≤ 1000`, `0 ≤ k ≤ 1000`.

Во второй строке записаны `n` целых чисел с фотографии, слева направо. Каждое число находится в диапазоне от −1000 до 1000.

## Формат вывода

Выведите числа, которые появятся в окошках после всех нажатий, слева направо, в одной строке через пробел.

## Пример 1

Ввод:

```text
5 2
10 20 30 40 50
```

Вывод:

```text
40 50 10 20 30
```

## Пример 2

Ввод:

```text
3 0
-1 0 1
```

Вывод:

```text
-1 0 1
```

## Пример 3

Ввод:

```text
3 4
1 2 3
```

Вывод:

```text
3 1 2
```

### Проверить готовое решение — Windows

Один раз [установите инструменты и клонируйте репозиторий]({{ '/tasks/' | relative_url }}).

```powershell
cd practice/homework/1/B-rotate
cmake -S . -B build-solution -G "NMake Makefiles" -DCOURSE_USE_SOLUTIONS=ON
if ($LASTEXITCODE -ne 0) { throw "Не удалось настроить сборку" }
cmake --build build-solution
if ($LASTEXITCODE -ne 0) { throw "Исправьте ошибки компиляции" }
```

Здесь собирается `solution.c`. Ваш `main.c` остаётся на месте, а результаты
сборки решения хранятся отдельно в `build-solution`.
`100% tests passed` означает успех; при ошибке показаны входной файл,
ожидаемый и полученный ответы. Тесты лежат в `tests/*.in` и `tests/*.out`.
