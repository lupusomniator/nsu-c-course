### Почему сначала нужна вся карта

Ответ для клетки — разность `maximum - a[i][j]`, где `maximum` относится
ко **всей** карте. Пока не прочитана последняя температура, максимум ещё
может измениться. Если сразу печатать ответы, исправить уже выведенные числа
после обнаружения более тёплой клетки не получится.

Сначала сохраняем карту в `a[100][100]`. Первый индекс обозначает строку,
второй — столбец. Во вложенных циклах `i` идёт от 0 до `n - 1`,
а `j` — от 0 до `m - 1`. Остальные ячейки большого массива не используются.

### Максимум должен начинаться с настоящего значения

После чтения присваиваем `maximum = a[0][0]`. Эта клетка существует,
поскольку обе размерности не меньше 1.

Инициализация нулём была бы ошибкой: на карте `-8 -3; -4 -9`
нет ни одной температуры 0, а правильный максимум равен `-3`.
При старте с нуля проверка `a[i][j] > maximum` ни разу не выполнится.

Для первого примера просмотр идёт так:

```text
3 8 2
7 1 5
```

| Просмотренная клетка | Значение | Максимум после сравнения |
| --- | ---: | ---: |
| `[0][0]` | 3 | 3 |
| `[0][1]` | 8 | 8 |
| `[0][2]` | 2 | 8 |
| `[1][0]` | 7 | 8 |
| `[1][1]` | 1 | 8 |
| `[1][2]` | 5 | 8 |

После каждой клетки `maximum` равен наибольшему из уже просмотренных значений.
Если новое число больше, оно становится новым максимумом; иначе прежний
максимум остаётся верным. Когда просмотрена вся матрица, получен общий максимум.

### Строим результат

Теперь `maximum == 8` и больше не меняется. Проходим по матрице ещё раз:

```text
8 - 3   8 - 8   8 - 2       5 0 6
8 - 7   8 - 1   8 - 5   →   1 7 3
```

Это обычное вычитание. Модуль не нужен: максимум не меньше ни одной клетки,
поэтому разность всегда неотрицательна. Вторую матрицу можно не создавать:
каждую готовую разность сразу печатаем.

Для отрицательного примера максимум `-3`, поэтому первая клетка даёт
`-3 - (-8) == 5`, а клетка с `-3` даёт 0. Знаки исходных чисел не меняют правило.

### Границы и типичные ошибки

- Ищем один максимум для всей карты. Отдельный максимум для каждой строки
  изменил бы смысл задачи: в первой карте вторая строка сравнивается тоже с `8`.
- При нескольких максимальных клетках каждая превращается в 0.
- Для одной клетки ответ — 0. Если все температуры равны, вся карта состоит из нулей.
- Исходные числа лежат от −1000 до 1000, значит, разность лежит от 0 до 2000.
  Для этих вычислений подходит `int`.
- В выводе остаётся `n` строк по `m` чисел. Выражение
  `j + 1 == m ? '\n' : ' '` завершает строку после последнего столбца.

Решение последовательно читает карту, находит максимум и печатает разности.
Эти три прохода разделены, чтобы у каждого была одна понятная роль.
