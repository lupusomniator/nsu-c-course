# D. Кот в серверной

Пока гости смотрели опыты, лабораторный кот пробрался в серверную. Маша подозревает, что он опять занял самое тёплое место. Заходить и искать кота между стойками долго, зато над дверью есть тепловизор.

Тепловизор прислал прямоугольную карту температур: `n` строк по `m` клеток. На экране слишком много чисел, поэтому Маша хочет заменить каждую температуру расстоянием до самой высокой температуры на всей карте — то есть разностью между самой высокой температурой и температурой этой клетки. Самые тёплые клетки станут нулями, а остальные покажут, на сколько градусов там холоднее. Если самых тёплых мест несколько, нулей тоже будет несколько.

Подготовьте такую карту. Кот, конечно, может оказаться хитрее тепловизора, но с чего-то поиск нужно начать.

## Формат ввода

В первой строке записаны размеры карты `n` и `m`, `1 ≤ n, m ≤ 100`.

В следующих `n` строках записано по `m` целых температур. Каждая температура находится в диапазоне от −1000 до 1000.

## Формат вывода

Выведите новую карту: `n` строк по `m` целых чисел. На месте каждой температуры должна стоять разность между максимальной температурой всей исходной карты и температурой этой клетки. Числа в каждой строке разделяйте пробелами.

## Пример 1

Ввод:

```text
2 3
3 8 2
7 1 5
```

Вывод:

```text
5 0 6
1 7 3
```

## Пример 2

Ввод:

```text
2 2
-8 -3
-4 -9
```

Вывод:

```text
5 0
1 6
```

## Пример 3

Ввод:

```text
1 1
7
```

Вывод:

```text
0
```

### Проверить готовое решение — Windows

Один раз [установите инструменты и клонируйте репозиторий]({{ '/tasks/' | relative_url }}).
Откройте **Developer PowerShell for VS**. Из корня клонированного
`nsu-c-course` выполните:

```powershell
cd practice/homework/1/D-temperature
cmake -S . -B build-solution -G "NMake Makefiles" -DCOURSE_USE_SOLUTIONS=ON
if ($LASTEXITCODE -ne 0) { throw "Не удалось настроить сборку" }
cmake --build build-solution
if ($LASTEXITCODE -ne 0) { throw "Исправьте ошибки компиляции" }
ctest --test-dir build-solution --output-on-failure
```

Здесь собирается `solution.c`. Ваш `main.c` остаётся на месте, а результаты
сборки решения хранятся отдельно в `build-solution`.
`100% tests passed` означает успех; при ошибке показаны входной файл,
ожидаемый и полученный ответы. Тесты лежат в `tests/*.in` и `tests/*.out`.
