### Индекс — номер записи, значение — само показание

В первом примере после чтения показаний массив содержит:

| Индекс | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Значение | 12 | −4 | 7 | 0 | −8 | 25 |

Запрос `5` означает «показание из ячейки с индексом 5».
Ответом будет `a[5]`, то есть `25`. Искать число `5` среди показаний не нужно:
запрос уже задаёт место, где лежит ответ.

### Почему сначала сохраняем все показания

Запросы поступают после завершения записи датчика. Если при чтении каждого
числа перезаписывать одну переменную, в конце останется только последнее
показание. Ответить на запрос про начало записи уже не получится.

Сохраняем число с номером `i` в `a[i]`. Тогда после первого цикла в массиве
лежит весь архив, и номер запроса можно использовать как индекс.

Сами запросы хранить не обязательно: ответ на очередной запрос не зависит
от последующих. Читаем `index`, печатаем `a[index]`, затем переходим к следующему.

### Разберём последовательность запросов

Для запросов `5 0 2 5 1`:

| Номер запроса по порядку | Прочитанный `index` | Обращение | Ответ |
| ---: | ---: | --- | ---: |
| 1 | 5 | `a[5]` | 25 |
| 2 | 0 | `a[0]` | 12 |
| 3 | 2 | `a[2]` | 7 |
| 4 | 5 | `a[5]` | 25 |
| 5 | 1 | `a[1]` | −4 |

Четвёртый запрос повторяет первый. Чтение `a[5]` не меняет содержимое ячейки,
поэтому снова выводится `25`. Удалять использованную запись или помечать её
как просмотренную не требуется.

### Как читать цикл решения

В цикле запросов переменная `i` считает, сколько запросов обработано.
Она **не является** номером нужного показания. Этот номер считывается отдельно
в переменную `index`. Поэтому выводим `a[index]`, а не `a[i]`.

По условию `0 <= index < n`. Все используемые ячейки уже заполнены первым
циклом. В `scanf("%d", &index)` нужен адрес переменной для записи;
в `printf("%d\n", a[index])` — само значение для вывода.

### Что важно на границах

- Нумерация начинается с нуля: первый элемент — `a[0]`, последний — `a[n - 1]`.
  Вычитать единицу из запроса не нужно.
- При `n == 1` возможен только индекс 0, но спрашивать его могут многократно.
- Количество запросов `q` может быть больше `n`: это нормально, записи повторяются.
- Отрицательное показание — обычное значение; его знак не влияет на индекс.
- Ответы идут в порядке запросов, каждый на своей строке.

Весь архив читается один раз, затем каждому запросу соответствует одно обращение
к массиву. Массив запросов и дополнительный массив ответов не нужны.
