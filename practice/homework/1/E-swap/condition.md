# E. Пульт перепутал провода

Для финала фестиваля Маша собрала большое табло из маленьких экранов. Каждый экран показывает целое число, а вместе они образуют прямоугольный числовой рисунок. На репетиции всё выглядело отлично. После перевозки верх и низ рисунка подозрительно поменялись местами, а некоторые столбцы будто решили уйти в гости к соседям.

Электрик проверил провода и оставил Маше записку: «Сначала поменять местами строки `r1` и `r2`. Потом поменять местами столбцы `c1` и `c2`. Больше ничего не трогать!» Если в какой-то паре он написал один и тот же номер дважды, эту часть рисунка менять не нужно.

Маша уже считала с табло все числа. Покажите, каким станет рисунок после выполнения записки, чтобы она могла сверить его перед выходом ведущего.

## Формат ввода

В первой строке записаны количество строк `n` и столбцов `m`, `1 ≤ n, m ≤ 100`.

В следующих `n` строках записано по `m` целых чисел — текущий рисунок на табло. Каждое число находится в диапазоне от −1000 до 1000.

Далее идут две строки из записки: сначала `r1` и `r2`, затем `c1` и `c2`. Строки нумеруются сверху вниз от 0 до `n - 1`, столбцы — слева направо от 0 до `m - 1`. Все указанные номера существуют.

## Формат вывода

Выведите рисунок после обеих перестановок: `n` строк по `m` целых чисел. Числа в каждой строке разделяйте пробелами.

## Пример 1

Ввод:

```text
2 3
1 2 3
4 5 6
0 1
0 2
```

Вывод:

```text
6 5 4
3 2 1
```

## Пример 2

Ввод:

```text
1 1
7
0 0
0 0
```

Вывод:

```text
7
```

## Пример 3

Ввод:

```text
3 2
-1 0
2 3
4 5
1 1
0 1
```

Вывод:

```text
0 -1
3 2
5 4
```

### Проверить готовое решение — Windows

Один раз [установите инструменты и клонируйте репозиторий]({{ '/tasks/' | relative_url }}).
Откройте **Developer PowerShell for VS**. Из корня клонированного
`nsu-c-course` выполните:

```powershell
cd practice/homework/1/E-swap
cmake -S . -B build-solution -G "NMake Makefiles" -DCOURSE_USE_SOLUTIONS=ON
if ($LASTEXITCODE -ne 0) { throw "Не удалось настроить сборку" }
cmake --build build-solution
if ($LASTEXITCODE -ne 0) { throw "Исправьте ошибки компиляции" }
ctest --test-dir build-solution --output-on-failure
```

Здесь собирается `solution.c`. Ваш `main.c` остаётся на месте, а результаты
сборки решения хранятся отдельно в `build-solution`.
`100% tests passed` означает успех; при ошибке показаны входной файл,
ожидаемый и полученный ответы. Тесты лежат в `tests/*.in` и `tests/*.out`.
Для проверки своего `main.c` используйте [общую инструкцию]({{ '/tasks/' | relative_url }}#как-проверять-решение).
