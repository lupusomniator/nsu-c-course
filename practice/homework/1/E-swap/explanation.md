### Что значит поменять две строки

Строка матрицы состоит из `m` элементов. Чтобы обменять строки `r1` и `r2`,
для каждого столбца `j` обмениваем `a[r1][j]` с `a[r2][j]`.
Индексы строк фиксированы, меняется только номер столбца.

Сначала читаем всю матрицу, затем четыре номера из записки. Вызов
`scanf("%d %d %d %d", &r1, &r2, &c1, &c2)` может прочитать их сразу:
при чтении целых чисел пробел в формате допускает и пробелы, и переводы строк.

Рассмотрим первую матрицу:

```text
1 2 3
4 5 6
```

Меняем строки 0 и 1:

| Столбец `j` | Какая пара обменивается | Матрица после обмена |
| ---: | --- | --- |
| 0 | `1` и `4` | `4 2 3` / `1 5 6` |
| 1 | `2` и `5` | `4 5 3` / `1 2 6` |
| 2 | `3` и `6` | `4 5 6` / `1 2 3` |

В каждой паре нужно сохранить первый элемент в `temp`: после записи второго
на его место исходное значение иначе потерялось бы.

### Теперь меняем столбцы

Столбец состоит из `n` элементов. Поэтому фиксируем `c1` и `c2`,
а по строкам проходим переменной `i`. На каждом шаге обмениваем
`a[i][c1]` и `a[i][c2]`.

В примере переставляем столбцы 0 и 2 **в уже изменённой матрице**:

```text
после обмена строк:     после обмена столбцов:
4 5 6                  6 5 4
1 2 3                  3 2 1
```

Обмен только четырёх клеток на пересечениях выбранных строк и столбцов
не заменяет эти действия: он оставил бы остальные элементы строк на месте.

### Почему достаточно двух отдельных циклов

При обмене строк каждый шаг работает с одной парой клеток в своём столбце.
Другие пары не затрагиваются. Когда пройдены все `m` столбцов, две строки
обменены целиком, а прочие строки не изменились.

Во втором цикле то же рассуждение применяется к двум столбцам и всем `n`
строкам. В результате выполнены обе команды из записки. Массив хранит
промежуточное состояние после первой команды, затем окончательный ответ.

### Особые случаи

- При `r1 == r2` каждая пара обозначает одну ячейку. Через `temp` в неё
  записывается прежнее значение: строка остаётся неизменной.
- При `c1 == c2` аналогично не меняется столбец. Отдельные проверки не обязательны.
- Для матрицы из одной строки номера строк могут быть только 0;
  столбцы при этом всё ещё могут переставляться.
- Для матрицы из одного столбца возможны перестановки строк.
- В прямоугольной матрице особенно важно не перепутать пределы:
  при обмене строк цикл идёт до `m`, при обмене столбцов — до `n`.

Размеры результата остаются `n × m`. При выводе `j + 1 == m ? '\n' : ' '`
ставит перевод строки после её последней клетки. Для перестановок нужен
только `temp`; второй матрицы в решении нет.
