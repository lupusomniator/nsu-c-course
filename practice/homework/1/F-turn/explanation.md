### Сначала повернём маленький рисунок

Возьмём две строки по три числа:

```text
1 2 3
4 5 6
```

При повороте по часовой стрелке левая колонка `1, 4` становится верхней
строкой, но читается снизу вверх: `4, 1`. Следующие колонки дают `5, 2`
и `6, 3`:

```text
4 1
5 2
6 3
```

Итак, в результате **три строки по два числа**. В общем случае размеры
`n × m` меняются на `m × n`. Для прямоугольной матрицы это существенно.

### Выводим формулу, а не запоминаем её

Пусть исходная клетка находится в строке `i`, столбце `j`.

1. Все клетки столбца `j` попадают в строку `j` результата.
   Значит, первый индекс результата равен `j`.
2. Нижняя клетка исходного столбца (`i == n - 1`) должна попасть на место 0,
   клетка над ней (`i == n - 2`) — на место 1, верхняя (`i == 0`) — на место `n - 1`.
   Этот обратный порядок задаёт выражение `n - 1 - i`.

Получаем перенос:

```c
result[j][n - 1 - i] = a[i][j];
```

Проверим все клетки первого примера:

| Исходные `(i, j)` | Значение | Новые `(j, n - 1 - i)` |
| --- | ---: | --- |
| `(0, 0)` | 1 | `(0, 1)` |
| `(0, 1)` | 2 | `(1, 1)` |
| `(0, 2)` | 3 | `(2, 1)` |
| `(1, 0)` | 4 | `(0, 0)` |
| `(1, 1)` | 5 | `(1, 0)` |
| `(1, 2)` | 6 | `(2, 0)` |

Углы тоже согласуются с условием: верхний левый переходит в верхний правый,
нижний левый — в верхний левый.

### Зачем отдельная матрица результата

Исходные значения ещё нужны для следующих переносов. Если сразу писать
повёрнутые элементы поверх `a`, можно затереть непрочитанную клетку.
Две матрицы `100 × 100` помещаются в ограничения и позволяют отдельно
читать источник и заполнять результат.

Все обращения находятся в границах. Из `0 <= j < m` следует допустимость
номера новой строки. Из `0 <= i < n` следует `0 <= n - 1 - i < n` —
допустимость номера нового столбца.

Каждая клетка результата получает ровно одно значение: по её координатам
`(row, column)` можно однозначно восстановить исходные
`j = row`, `i = n - 1 - column`. Поэтому после переноса можно выводить
все `m × n` клеток результата; незаполненных мест среди них нет.

### Поворот и транспонирование — разные действия

Запись `result[j][i] = a[i][j]` лишь меняет местами строки и столбцы.
Для первого примера она дала бы `1 4`, `2 5`, `3 6`: порядок внутри новых
строк не перевёрнут. Это транспонирование, а не требуемый поворот.
Вычитание `n - 1 - i` как раз создаёт недостающий разворот.

### Границы и вывод

- Одна исходная строка становится столбцом: `-1 0 7` превращается в три строки.
- Один исходный столбец становится строкой в обратном порядке:
  `8, 9, 10` сверху вниз превращаются в `10 9 8` слева направо.
- Одна клетка остаётся собой.
- При выводе внешний цикл идёт до `m`, внутренний — до `n`.
  Условие `j + 1 == n` выбирает перевод строки после последнего столбца
  **новой** матрицы. Старые размеры здесь дали бы неверное число строк и чисел.
