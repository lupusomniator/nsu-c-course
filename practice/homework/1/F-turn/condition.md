# F. Афиша набекрень

Фестиваль почти начался, и осталась последняя мелочь: вывести на экран афишу. Художники придумали числовую мозаику — прямоугольный рисунок, в каждой клетке которого стоит целое число. Издалека это искусство, вблизи — отличный повод вспомнить программирование.

Но файл подготовили для горизонтального экрана, а экран установили вертикально. Монтажник предлагает повернуть всю конструкцию вместе со стеной. Маша выбирает более спокойный вариант: повернуть сам рисунок на 90 градусов по часовой стрелке. При таком повороте верхний левый угол окажется в верхнем правом, а нижний левый — в верхнем левом.

Подготовьте повёрнутую мозаику. Все числа должны остаться на рисунке, даже если художники уверяют, что некоторые из них «только для настроения».

## Формат ввода

В первой строке записаны высота `n` и ширина `m` исходной мозаики, `1 ≤ n, m ≤ 100`.

В следующих `n` строках записано по `m` целых чисел. Каждое число находится в диапазоне от −1000 до 1000.

## Формат вывода

Выведите повёрнутую мозаику: `m` строк по `n` целых чисел. Числа в каждой строке разделяйте пробелами. Размеры мозаики отдельно выводить не нужно.

## Пример 1

Ввод:

```text
2 3
1 2 3
4 5 6
```

Вывод:

```text
4 1
5 2
6 3
```

## Пример 2

Ввод:

```text
1 3
-1 0 7
```

Вывод:

```text
-1
0
7
```

## Пример 3

Ввод:

```text
3 1
8
9
10
```

Вывод:

```text
10 9 8
```

### Проверить готовое решение — Windows

Один раз [установите инструменты и клонируйте репозиторий]({{ '/tasks/' | relative_url }}).
Откройте **Developer PowerShell for VS**. Из корня клонированного
`nsu-c-course` выполните:

```powershell
cd practice/homework/1/F-turn
cmake -S . -B build-solution -G "NMake Makefiles" -DCOURSE_USE_SOLUTIONS=ON
if ($LASTEXITCODE -ne 0) { throw "Не удалось настроить сборку" }
cmake --build build-solution
if ($LASTEXITCODE -ne 0) { throw "Исправьте ошибки компиляции" }
ctest --test-dir build-solution --output-on-failure
```

Здесь собирается `solution.c`. Ваш `main.c` остаётся на месте, а результаты
сборки решения хранятся отдельно в `build-solution`.
`100% tests passed` означает успех; при ошибке показаны входной файл,
ожидаемый и полученный ответы. Тесты лежат в `tests/*.in` и `tests/*.out`.
Для проверки своего `main.c` используйте [общую инструкцию]({{ '/tasks/' | relative_url }}#как-проверять-решение).
