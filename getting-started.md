# Начало работы

1. [Настройте редактор](how_to_ide.md): VSCode или CLion.
2. [Установите инструменты сборки](how_to_cmake.md#подготовка-инструментов):
   компилятор Си, CMake и инструмент сборки.
3. [Клонируйте репозиторий задач и запустите тесты](tasks.md).
4. Посмотрите [правила оформления кода](how_to_codestyle.md).

[Работа с Git и сдача работ](how_to_git.md) описывает ветки, коммиты,
отправку решений и исправления после проверки. Для лабораторных сохранена
[инструкция по сборке и TestDriver](how_to_cmake.md).
