# Программирование на C: материалы курса

Здесь собраны инструкции для работы с Си, задачи с семинаров и домашек,
разборы решений и тесты для самостоятельной проверки.

## Начать работу

[Начало работы](getting-started.md) — настройка редактора, сборка, тестирование,
Git и правила оформления кода.

## Решать и повторять

- [Задачи](tasks.md) — семинары и домашки. У каждой опубликованной задачи есть
  условие, полный разбор, решение и тесты.
- [Материалы](materials.md) — раздел с теорией по темам курса.

Чтобы решать задачи локально, достаточно один раз клонировать репозиторий.
Команды для Windows приведены в [разделе задач](tasks.md); на каждой странице
указано, в какую папку перейти и как запустить тесты.
