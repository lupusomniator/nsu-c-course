# Материалы

Теория C17 с пошаговыми примерами, объяснением типичных ошибок и упражнениями
с раскрывающимися ответами. Сначала попробуйте предсказать результат программы,
затем запустите её и сравните вывод со своим ответом.

| Материал | Что разберём |

| [Как числа хранятся в битах](materials/numbers.md) | Целые числа, дополнительный код, переполнение, IEEE 754 и округление |

Материалы можно читать по порядку или выбирать нужную тему. Достаточно знать
переменные, условия, циклы, массивы, функции и основы указателей.
В каждой теме есть три упражнения с ответами.

Для семинара **15.10.2026** основные темы — структуры и макросы.
Материалы о числах, стеке и областях видимости помогают разобраться
с представлением данных и временем жизни объектов.

Задачи для самостоятельной работы находятся в [разделе практики](tasks.md),
а настройка компилятора — в [инструкции по началу работы](getting-started.md).

## Запуск примеров

В каталоге `materials/examples/` лежат восемь самостоятельных программ:

| Файл | Что проверить |
| --- | --- |
| [structBasics.c]({{ '/materials/examples/structBasics.c' | relative_url }}) | Копирование структуры, передача по значению и по указателю |
| [structLayout.c]({{ '/materials/examples/structLayout.c' | relative_url }}) | `sizeof`, `offsetof`, `_Alignof`, перестановка полей и `pack` |
| [macros.c]({{ '/materials/examples/macros.c' | relative_url }}) | Приоритет операций, повторное вычисление, `#` и `##` |
| [decodeHeader.c]({{ '/materials/examples/decodeHeader.c' | relative_url }}) | Чтение числа из байтов без приведения к указателю на структуру |
| [stackFrames.c]({{ '/materials/examples/stackFrames.c' | relative_url }}) | Рекурсивные вызовы, локальный `static` и скрытие имён |
| [variableArray.c]({{ '/materials/examples/variableArray.c' | relative_url }}) | Размер локального массива при выполнении; требуется GCC / Clang с поддержкой VLA |
| [numberBits.c]({{ '/materials/examples/numberBits.c' | relative_url }}) | Биты и байты целых чисел, представление `float` |
| [floatPrecision.c]({{ '/materials/examples/floatPrecision.c' | relative_url }}) | Округление, потеря точности и порядок вычислений |

Из корня репозитория перейдите в каталог `materials` командой `cd materials`.
Следующие команды выполняются из этого каталога. Каждый файл собирайте отдельно:
в каждом есть свой `main`. Примеры с намеренными ошибками помечены в тексте;
неопределённое поведение в запускаемые программы не включено.

macOS / Linux (Clang или GCC):

```sh
cc -std=c17 -Wall -Wextra -Wpedantic examples/structBasics.c -o /tmp/structBasics
/tmp/structBasics
```

Windows, **Developer PowerShell for VS** (MSVC с поддержкой C17):

```powershell
cl /nologo /TC /std:c17 /W4 /utf-8 examples/structBasics.c /Fe:structBasics.exe
if ($LASTEXITCODE -eq 0) { .\structBasics.exe }
```

Для другого примера замените имя файла и программы. `#pragma pack` — расширение
компилятора: его поведение разбираем для GCC, Clang и MSVC; численные результаты
измерений зависят от платформы.

Для `floatPrecision.c` на Linux при необходимости добавьте `-lm` в конец
команды компиляции для подключения математической библиотеки. Численные
примеры с плавающей точкой рассчитаны на обычное округление к ближайшему,
`float` binary32 и `double` binary64, без `-ffast-math` и аналогичных режимов.
